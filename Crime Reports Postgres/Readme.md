This project is based on crime reports in Boston, and was done on postgres server. This project is a hands-on project for Data engineers where you configure the users and database on Postgres SQL server using psycopg2 library.


This project creates users, and managers the permission based on Privilege of least principle -security best practice on Boston crime reports. 


Instead of performing analysis - this project works on data engineer responsibilities of creating schemas, table definitions, and building datasets for users
